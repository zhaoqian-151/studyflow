# FastAPI 学习笔记

## 数据隔离

业务记录关联 user_id，服务端通过已校验的登录会话获取当前用户。
列表查询按 user_id 过滤，按 ID 修改前检查所有权。不要信任客户端提交的用户身份。
访问其他用户的私有记录返回 404。

## 请求级数据库会话

FastAPI 通过 Depends 注入数据库 Session 和当前用户。
每个请求独立管理 Session，异常时回滚未提交事务，结束后关闭连接。
同步 ORM 在异步路由中的阻塞成本需要结合实际负载评估。

## 专注与幂等

服务端保存 started_at、minutes，完成时检查经过的时间。
request_id 唯一约束避免重复开始，部分唯一索引限制每个用户一个活动专注。
重复完成同一个记录不会增加额外学习时长。
